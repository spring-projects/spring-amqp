[[changes-in-4-1-since-4-0]]
== Changes in 4.1 Since 4.0

[[x41-tls-hostname-verification]]
=== TLS Hostname Verification

`RabbitConnectionFactoryBean#setEnableHostnameVerification(boolean)` is deprecated since 4.1.
Since `amqp-client` 5.33, hostname verification is enabled automatically when TLS is configured via `useSslProtocol`.
Spring AMQP now depends on `amqp-client` 5.33.0.
When `skipServerCertificateValidation` is `true`, the factory bean now delegates to
`ConnectionFactory#useTlsWithNoVerification()` (and `sslAlgorithm` is ignored in that path).

[[x41-amqp10-client]]
=== AMQP 1.0 Client

A new `spring-amqp-client` module has been introduced to provide support for interacting with generic AMQP 1.0 protocol.
See xref:amqp10-client.adoc[] for more information.
